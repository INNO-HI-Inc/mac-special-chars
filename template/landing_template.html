설치 — 1분

Hammerspoon 같은 별도 프로그램 없이, 맥에 원래 있는 「텍스트 대치」 기능만 씁니다.

  1. 텍스트 대치 파일 받기

    아래 버튼을 누르면 특수문자_텍스트대치.plist 가 다운로드 폴더에 저장돼요.

    ⬇ 다운로드 (@@PLIST_KB@@KB)

  2. 시스템 설정 → 키보드 → 텍스트 대치… 열기

    화면 왼쪽 위 Apple 메뉴 → 시스템 설정 → 키보드 → 아래쪽 텍스트 대치… 버튼

  3. 받은 파일을 목록 안으로 드래그

    목록에 @@COUNT@@개가 한 번에 추가됩니다. 이제 한글 모드에서 ㅁ별 + 스페이스 → ★. 되돌리려면 변환 직후 ⌘Z.

이런 기호들이 들어 있어요

모든 단축어는 ㅁ 로 시작합니다 — 한글 타이핑에서 「ㅁ+글자」는 자연스럽게 나오지 않아 오작동이 없어요. 눌러보면 복사됩니다.

자주 묻는 것

단축어를 쳤는데 안 바뀌어요

한글 입력 상태에서 단축어를 치고 스페이스를 눌러야 바뀝니다. 영문 모드에서는 동작하지 않아요. 그래도 안 되면 시스템 설정 → 키보드 → 텍스트 대치 목록에 항목이 들어갔는지 확인하세요.

일부 앱에서만 안 돼요

텍스트 대치는 macOS 표준 텍스트 입력 필드에서 동작합니다. 자체 입력기를 쓰는 일부 앱 (터미널, 일부 Electron·게임 앱, VS Code 등)에서는 적용되지 않아요. 그런 앱에서는 ⌥ Space 팔레트를 쓰면 됩니다.

iPhone·iPad에서도 되나요

됩니다. 맥과 같은 iCloud 계정을 쓰고 「iCloud → 설정 및 데이터 동기화」가 켜져 있으면 텍스트 대치 목록이 자동으로 넘어갑니다. 몇 분 걸릴 수 있어요.

기호를 추가하거나 바꾸고 싶어요

저장소를 받아 entries.json 을 고치고 python3 scripts/build.py 를 돌리면 plist · 치트시트 · 팔레트가 한 번에 다시 만들어집니다. 연락처·계좌번호처럼 공개하면 안 되는 값은 entries.local.json (git 제외) 에 넣으세요.

지우고 싶으면요

시스템 설정 → 키보드 → 텍스트 대치에서 항목을 선택하고 − 버튼을 누르면 됩니다. 팔레트는 저장소에서 ./uninstall.sh.
